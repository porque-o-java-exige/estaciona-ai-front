# Coming Soon

Tela de aviso para funcionalidades ainda não disponíveis, baseada na referência em `src/assets/screens/coming-soon/coming-soon-screen.png`.

## Rota

`/profile/coming-soon`

## Assets

- `assets/images/png/coming-soon-illustration.png`: ilustração da tela.
- `assets/icons/png/chevron-left-icon.png`: ação para voltar ao perfil.

## Execução

Abra a rota em `http://localhost:4200/profile/coming-soon` depois de iniciar a aplicação com `npm start`.
